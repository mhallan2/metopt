\subsection{Проверка свойства выпуклости через пересечение}

Рассматриваются множества
\begin{align*}
    A &= \{(x,y) : x^2 + y^2 \leq 3^2\}, \\
    B &= \{(x,y) : (x-2)^2 + (y-1)^2 \leq 2.5^2\}.
\end{align*}
% \[
% 	A=\{(x,y):x^2+y^2\leq 3^2\},
% \]
% \[
% 	B=\{(x,y):(x-2)^2+(y-1)^2\leq 2.5^2\}.
% \]

% \textbf{Вопрос для проверки.}
% \textit{Является ли пересечение двух кругов выпуклым множеством? Всегда ли
% пересечение выпуклых множеств выпукло? Ответьте, основываясь на полученном
% графике и теоретическом свойстве.}

% \textbf{Ответ.}
% Да, пересечение двух кругов является выпуклым множеством. Каждый круг
% выпуклый, поскольку для любых двух его точек отрезок, соединяющий эти
% точки, целиком лежит внутри круга.


% На графике пересечение кругов $A\cap B$ представляет собой линзовидную
% область без выемок. Поэтому для любых двух точек этой области отрезок
% между ними также принадлежит пересечению.

% Согласно доказанной теореме~\ref{thm:intersection}, пересечение любого семейства
% выпуклых множеств является выпуклым множеством.

% Таким образом, пересечение двух кругов в данной задаче выпукло. Более
% того, пересечение любого числа выпуклых множеств всегда выпукло. При этом
% пересечение может быть пустым; пустое множество также считается выпуклым.

\subsection{Проверка критерия выпуклости}

Функция \texttt{is\_convex} векторизованно вычисляет знаки
ориентированных произведений последовательных рёбер
$c_i = \overrightarrow{(p_{i+1}-p_i)} \times
\overrightarrow{(p_{i+2}-p_{i+1})}$.
Все $c_i$ вычисляются одновременно; булевой маской исключаются
коллинеарные тройки. Многоугольник признаётся выпуклым,
если все оставшиеся $c_i$ одного знака, либо если таковых не осталось
(все точки коллинеарны). Сложность~--- $O(n)$, хотя в случае, когда
передается много невыпуклых многоугольников, программа обречена
делать полные проходы по массиву и считать всевозможные векторные
произведения, когда в реальности могло бы сработать условие раннего выхода из цикла. В тестах
использованы
выпуклый многоугольник с коллинеарной точкой, невыпуклый и звездообразный многоугольники.
