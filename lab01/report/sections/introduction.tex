\section{Цель работы}

Изучить и программно реализовать численные методы одномерной минимизации унимодальных и
многоэкстремальных функций, провести сравнительный анализ их эффективности.

Среди реализованных методов для поиска локального минимума унимодальных функций
были выбраны следующие:
\begin{itemize}
    \item пассивный поиск;
    \item метод дихотомии;
    \item метод Фибоначчи;
    \item метод золотого сечения;
    \item метод парабол.
\end{itemize}

А также алгоритмы поиска глобального минимума многоэкстремальных функций:
\begin{itemize}
    \item равномерный поиск;
    \item метод ломаных.
\end{itemize}
